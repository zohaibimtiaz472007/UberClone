# 🚖 UberClone

UberClone is a full-stack ride booking application inspired by modern ride-sharing platforms like Uber.  
Built using the MERN Stack, this project provides a complete real-world experience for both users and captains (drivers), featuring authentication, ride booking, live ride management, and responsive modern UI design.

The application is designed with scalable architecture, clean code practices, and production-level project structure to strengthen full-stack development skills and portfolio quality.

---

## ✨ Features

### 👤 User Features
- User Authentication & Authorization
- Secure Login & Registration
- Book Rides Easily
- Choose Different Vehicle Types
- Fare Estimation
- Live Ride Status Updates
- Responsive Modern UI
- Location-Based Ride Experience

### 🚖 Captain (Driver) Features
- Captain Authentication
- Online/Offline Availability
- Ride Acceptance & Management
- Driver Dashboard
- Ride Confirmation Flow
- Earnings & Ride Handling

### ⚙️ Backend Features
- RESTful API Architecture
- JWT Authentication
- MongoDB Database Integration
- Real-Time Communication using Socket.IO
- Secure Password Hashing
- Modular Backend Structure
- API Documentation Included
