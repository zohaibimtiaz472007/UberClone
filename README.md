# 🚖 UberClone

A full-stack Uber Clone application built using the MERN Stack with a modern and responsive UI powered by Tailwind CSS.  
This project includes separate frontend and backend architectures with complete authentication and ride management features.  
The backend API documentation is available inside the `backend` folder, and the frontend documentation is available inside the `frontend` folder.  
It is designed to provide a real-world ride booking experience with users and captains (drivers).  
Built to improve full-stack development skills, portfolio quality, and production-level application structure.
